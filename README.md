# 모여봐

최대 30명이 한 광장에서 걸어 다니고, 채팅하고, 미니게임을 하는 실시간 메타버스입니다.

## 실행

```bash
npm install
npm start
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

## 기능

- 닉네임 변경, 아바타 색상 선택
- 앉기, 찌르기, 달리기
- 실시간 채팅
- 방장 권한: 미니게임 시작/종료, 강퇴, 채팅 금지, 방장 위임, 방 잠금
- 미니게임: 좀비, 초성, 똥피하기, 색칠하기, 폭탄 옮기기

공개 광장 코드는 `PLAZ` 입니다. 새 방을 만들면 4자리 코드가 생깁니다.
